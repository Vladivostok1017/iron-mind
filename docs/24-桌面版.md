# 24 · 桌面版：从"能跑"到"能装"

前面二十几篇讲的都是**这场战争怎么模拟**。这一篇讲的是另一件事：
怎么让一个不懂 Rust、不会开终端的人，**双击一个图标就能玩**。

这两件事没有关系，所以放在最后单独说——引擎的规则一行没改，
只是多了一个窗口外壳和一个首页。

---

## 1. 为什么需要这一层

在这之前，跑起来是这样的：

```powershell
$env:IRONMIND_MODULES = "F:\dsh\nanxun-1938"
cargo run -p sim-server
# 然后自己去浏览器打开 http://127.0.0.1:8899
```

对开发者这没问题。对玩家这就是**不可发布**：

| 问题 | 后果 |
|---|---|
| 要装 Rust、要编译 | 99% 的人走不到第二步 |
| 要开浏览器、输地址 | 看起来像个网页工具，不像游戏 |
| 端口写死 8899 | 同时开两局会撞在一起 |
| 没有入口页 | 一进来是张没名字的地图，不知道下一步干什么 |
| 没有引导 | 这个游戏的规则和别人不一样（不能直接动部队），不教就是劝退 |
| 存档靠 `prompt()` | 那个浏览器弹窗一眼就被看穿"这其实是个网页" |

桌面版要解决的就是这六条。

---

## 2. 结构：多了一个 `sim-desktop`，别的一层没动

```
┌──────────────────────────────────────────┐
│ IronMind.exe        (crates/sim-desktop) │  ← 原生窗口 + 拉起内核
│   ├─ WebView2 窗口                        │
│   └─ 子进程：sim-server.exe --port <随机> │
└──────────────────────────────────────────┘
                    │ localhost HTTP
┌──────────────────────────────────────────┐
│ sim-server (内核 + 页面)                  │
│   sim-core / sim-content                  │
└──────────────────────────────────────────┘
```

**外壳不含任何战役逻辑**，它只做四件事：

1. 找一个空闲端口（不跟开发时的 8899 抢）；
2. 把 `sim-server` 作为子进程拉起来，**关窗就杀掉**，不留后台进程；
3. 等内核就绪（最多 25 秒）再开窗口，避免玩家看到一片错误页；
4. 读安装目录的 `settings.env`，作为子进程的环境变量。

窗口用 `tao` + `wry`（WebView2）。为什么不自己画 UI：
地图是 SVG、面板是 DOM，这套东西在 Web 里已经写完了，
换成原生绘制等于把二十几篇文档里的界面全部重写一遍。

---

## 3. 装成什么样

```powershell
pwsh -File install.ps1                    # 编译 + 安装 + 建快捷方式
pwsh -File install.ps1 -Uninstall         # 卸载（存档会先备份）
```

装完是这样一个目录（**不需要管理员**，全在 `%LOCALAPPDATA%`）：

```
%LOCALAPPDATA%\IronMind\
  IronMind.exe                    外壳
  sim-server.exe                  内核
  ironmind.ico                    图标
  modules\                        模块（换战役不用重新编译）
    demo_1805.imod\
    siege_tianjiazhen.imod\
    nanxun_1938.imod\
  settings.env                    配置（记事本可改）
  saves\                          存档（命令流）
  logs\desktop.log                外壳 + 内核的日志
  IronMind.exe.WebView2\          浏览器运行时数据（含引导是否看过）
```

装完会有：

- 开始菜单 →「钢心」
- 桌面 →「钢心」
- 设置 → 应用 → 已安装的应用 →「钢心」（可卸载）

`install.ps1` 的参数：

| 参数 | 说明 |
|---|---|
| `-Dir` | 装到别处 |
| `-Modules` | 额外要装进去的模块目录（可多个） |
| `-DefaultModule` | 第一次打开时先加载哪个战役（名字或全路径） |
| `-SkipBuild` | 直接用 `target\release` 里现成的产物 |
| `-NoShortcuts` | 不建快捷方式 |
| `-Uninstall` | 卸载 |

## 4. `settings.env`：给"只会双击图标的人"一条配置通路

玩家的桌面上没有环境变量面板，但有记事本。

```ini
# 一行一个 KEY=VALUE，# 开头是注释
# IRONMIND_LLM=off
# IRONMIND_API_KEY=sk-................
# IRONMIND_MODEL=deepseek-chat
# IRONMIND_API_BASE=https://api.deepseek.com/v1
# IRONMIND_HQ_INTERVAL=2
# IRONMIND_MODULES=D:\my-modules
```

**优先级：系统环境变量 > `settings.env` > 程序默认。**

方向是刻意的：命令行上临时调试时，不能被文件里的旧值盖掉。
外壳只把**键名**写进日志，值（可能是 API key）绝不落盘到日志里。

默认不联网：没填 API key 时，将领大脑走本地模拟判断，
规则、地形、战斗、结局全都正常——只是将领的"脑子"简单一些。

## 5. 首页

启动即显示，**不等内核**。引擎没好时按钮是灰的、状态栏写"连接中"，
而不是让玩家盯着一块黑屏。

| 项 | 说明 |
|---|---|
| 继续 | 读最近的一份存档；没有存档时这一项是灰的，主角换成"新的战役" |
| 新的战役 | 列出所有模块：名字、规模、版本、扮演哪一边、这段战史在讲什么 |
| 读取存档 | 列出槽位（第几日 / 几条命令 / 时间），点一下就读 |
| 上手引导 | 六步，随时可以重看 |
| 设置 | 将领大脑状态、模型、会商间隔、模块目录、存档目录、最近的模型错误 |
| 关于 | 这个引擎坚持什么、不做什么 |

右侧的**战役卡**显示当前模块：名字、规模、描述、第几日、我军兵力、敌军估计。

> 敌军估计写"未查明"而不是"约 0.0 千"。
> 情报是情报，事实是事实——一点没侦察到时写 0，等于骗玩家说敌人不存在。

顶栏的国名/战区名也是从模块读的。之前那两个字是写死在 HTML 里的，
换一场战役左上角还挂着上一场仗的番号——那是引擎越界了。

## 6. 引导：只讲"和别人不一样的地方"

这个游戏有三件事反直觉，不说清楚就是劝退：

1. **你不能拖动部队。** 唯一的指挥手段是电报，一句话说清意图。
2. **将领有独立判断。** 会追问，会抗命，抗命的结果也会进战报。
3. **没有"你赢了"。** 战役结束给出的是一条结局和它的依据。

所以引导只有六步，每一步都指着一个真实存在的控件（地图、电报台、
公文堆、推进按钮、战报信箱），最后一步回到这三条原则：

| 步 | 目标 | 讲什么 |
|---|---|---|
| 1 | 地图 | 地形是真的：高程、河网、铁路来自模块 |
| 2 | 电报台 | 唯一的下令方式；收报人可以细到师 |
| 3 | 公文堆 | 请示要你批，抗命不会悄悄消失 |
| 4 | 推进 1 日 | 空格 = 一天，回车 = 推进到有事；时间最贵 |
| 5 | 战报信箱 | 战报会迟到，所以要预判而不是反应 |
| 6 | —— | 没有胜负，只有结局 |

实现上是一个 3 像素的洞 + `box-shadow: 0 0 0 9999px` 当遮罩：
**被高亮的东西仍然可点**，因为它只是没被遮住，不是被盖住了。
卡片位置按"右边有地方就放右边，否则左边，否则翻到上面"算——
底栏那几个按钮就在屏幕最下沿，卡片必须往上翻，不然正好盖住要高亮的东西。

跳过也算看过（`localStorage.im_onboarded`），之后不再打扰。
重看走首页的"上手引导"。

## 7. 存档、日志、诊断

- 存档：`saves\*.json`，存**命令流**不是世界快照；读档重跑并核对哈希。
- 日志：`logs\desktop.log`，外壳和内核写同一份（`[desktop]` 是外壳的行）。
- 报 bug 时最有用的三样：`logs\desktop.log`、`settings.env`、首页"关于"里
  显示的版本号（`/api/version` 从 `CARGO_PKG_VERSION` 取，不会和代码脱节）。

## 8. 已知限制（写下来比藏起来好）

| 限制 | 说明 |
|---|---|
| 需要 WebView2 | Win11 和新版 Win10 自带；老系统要装一次微软的 Evergreen 运行时 |
| 没有代码签名 | 首次运行可能有 SmartScreen 提示（点"更多信息 → 仍要运行"） |
| 设置不能在线改 | 只能改 `settings.env` 再重启；`/api/llm/config` 这种接口还没做 |
| 没有自动更新 | 重跑一次 `install.ps1` 就是更新 |
| 单实例没做 | 同时开两个会各起一个内核；存档目录共享，可能互相覆盖 |
| exe 本身没嵌图标 | 快捷方式有图标（指向 `.ico`），资源段里的图标还没做（要 `rc.exe`） |
| 端口随机 | 好处是不撞车；代价是没法用固定地址访问（要固定就命令行传 `--port`） |

## 9. 验证方法

界面改动不能靠"看起来没问题"——已经被缓存的旧页面骗过两次。都走无头：

```powershell
# 首页
node tools/shot.js --url http://127.0.0.1:8899/ --out tools/_shots/home.png --wait 2200
# 引导第 N 步
node tools/shot.js --url http://127.0.0.1:8899/ --out tools/_shots/g2.png --wait 2200 `
  --eval "(async()=>{Home.hide();await new Promise(r=>setTimeout(r,600));Guide.next();return document.getElementById('gd-title').textContent})()"
```

原生窗口本身用截图确认：标题应为「钢心 · Iron Mind」，
`logs\desktop.log` 里应能看到 `[desktop] 启动 ... port=...` 与
`[desktop] 内核就绪 http://127.0.0.1:.../`。
