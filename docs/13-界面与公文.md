# 界面与公文

> 照着《钢铁雄心4》的布局重排了一次。核心不是"抄它的样子"，是抄它的**信息分层**：
> 顶栏放摘要、顶上放警示、右侧全给部队、左侧给地图模式，主地图永远居中不被挤。

参考：[HOI4 官方 wiki · User interface](https://hoi4.paradoxwikis.com/User_interface)

---

## 1 HOI4 的做法（我读到的原文要点）

> "The left hand of the screen will be used to manage large national issues,
> alert tabs will appear at the top of the screen as a warning of things that need attention,
> and **the right hand side of the screen will be devoted to information about troops**.
> The very top border will include important summary information about the state of the game."

拆开就是四条规矩：

1. **顶栏是一排数字**，不是菜单：政治力、稳定、战争支持、人力、工厂、燃料、后勤满足度、指挥力。
2. **警示标签在屏幕上方**——有事要你管的时候，往上顶，不让你翻栏找。
3. **右侧全是部队**：选中详情 + 部队列表（outliner），点列表选部队，不用在图上找。
4. **左侧是国家大事与地图模式**，主地图居中。

## 2 我们的映射

| HOI4 | 我们 |
|---|---|
| 顶栏资源排 | 第几日 / 我军兵力 / 控制省份 / 敌军估计 / **请示 N 份待批**（金色） |
| 顶部警示标签 | `#pending` 徽标：有待批请示时变金色并显示数量 |
| 右侧部队详情 | 阵地面板 + 选中单位 |
| 右侧 outliner | **部队列表**：番号 · 所在省·阵地 · 兵力 · 当前命令，点一行即选中 |
| 左侧地图模式 | 底栏四个模式（归属/情报/补给/地形），下一步移到左侧竖排 |
| 时间控制 | 底栏：推进 1 日 / 3 日（下一步加暂停与"推进到下一事件"） |

## 3 公文堆：右侧栏不该是流水账

现在是三栏信息：**公文堆 / 部队 / 战报**。区别在于"要不要你做事"：

| 类型 | 何时产生 | 玩家要做什么 | 处理方式 |
|---|---|---|---|
| **请示** `request` | 中方将领想改令 | **必须做决定** | 「准他改令」/「驳回，维持原令」 |
| **抗命** `dissent` | 日方将领擅自改令、或请示逾期 | 只需知道 | 只读 |
| **通报** `notice` | 将领同意上级 | 不用管 | 只读（进战报） |

### 过期是设计的核心

请示带 `deadline = 当日 + 2`。到点没批：

```
第29军团（李汉魂）：请示无人答复，已自决改令 fortify
```

**不回答本身就是一个决定**——这正是指挥链摩擦该有的样子。玩家可以选择不看，
但代价是把指挥权交回给将领。

### 为什么日方不用请示

玩家是中方统帅。日方将领没有上级可问，他的抗命直接执行、只记通报。
这不是双标，是"你只坐在一方的指挥部里"。

## 4 顺带修掉的一个真 bug：问询饿死

预算只有每 tick 3 单时，如果按单位索引顺序取，0/1/2 号单位每 tick 都到期，
会永远占住三个名额——**中方部队一次都轮不到**。

改成"最久没问过的优先"排队后，18 个单位在 6 天里全部轮到。
这是成本控制最容易踩的坑：限流不能按索引限。

## 5 还没做

- 地图模式栏移到左侧竖排（照 HOI4）
- 时间控制条：暂停 / 变速 / **推进到下一事件**（依赖事件流，已经具备）
- 补给与后勤做成独立的侧栏 tab：现在只有地图模式，没有"哪支部队快断粮"的清单
- 框选与拖拽下令
