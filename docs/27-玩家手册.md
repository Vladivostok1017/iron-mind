# 钢心 · 玩家手册

> 这一份是**给玩家看的**：怎么玩、每个数字是什么意思、为什么这一仗打不动。
> 引擎内部怎么实现看 `docs/` 里编号的那些设计文档，这里不讲代码。

---

## 0 三句话规则

1. **你不是操作单位的人，你是下命令的人。** 命令传下去，将领去执行 —— 他可能照办、
   打折扣、甚至抗命，而且传令要时间。
2. **你看到的是情报，不是真值。** 地图上的敌军数字是"打听到的"，可能过期、可能不准。
3. **后勤决定你能打多久。** 补给沿补给源 → 铁路/水道/公路流动，一路衰减；
   断了粮会死人，跟打输了一样。

## 1 第一天：五分钟上手

| 步骤 | 做什么 | 在哪 |
|---|---|---|
| 1 | 选一个战役（模块） | 首页 →「新的战役」→ 点模块 → 选阵营 |
| 2 | 认一下自己的部队 | 右侧「部队」列表；或点地图上的我方兵牌 |
| 3 | 发一封电报 | 右侧「电报台」→「发给」选**整个兵团**或**某一支部队** → 写人话 → 发出 |
| 4 | 推进一天 | 底部「推进 1 日」（快捷键 <kbd>空格</kbd>） |
| 5 | 看战报 | 右侧「战报」→「打开战报信箱」；带「在途」的是还在路上的 |

**第一天最该做的三件事**：看一眼自己的补给线通不通、看一眼当面敌军大概多少、
给挨着敌人的那支部队下一道明确的令（模糊的令会被将领按自己的性格理解）。

## 3 地图怎么读

### 四个视图

| 视图 | 画什么 | 什么时候用 |
|---|---|---|
| **归属** | 谁控制这个省（颜色） | 默认。看战线 |
| **情报** | 你对敌情的掌握程度 | 找"我根本不知道对面有多少人"的地方 |
| **补给** | 每省的补给水平（颜色深浅） | 判断"这支部队还能撑几天" |
| **地形** | 真实高程（山脉、河谷） | 判断为什么这条路难走、这里好守 |

### 图上的符号

| 符号 | 含义 |
|---|---|
| 省名 | 白字＝我方控制，暗红＝敌方。太小的省不写名字，悬停/点击看 |
| `≈12` | 这一省敌军的**估计**兵力（千）。没侦察到就不显示 |
| `砦3` | 该阵地的工事等级（0–5）。每级 +15% 防御 |
| 兵牌 `兵`/`机`/`舰` | 一支部队。蓝＝我方，红＝敌方。放大后牌子里显示**番号短码**（`38军`、`106师`） |
| 兵牌左上小数字 `2` | 这支部队站在本省**第 2 个阵地** |
| 红虚线环 +「战」 | 这一省里敌我**地面部队同时存在** —— 正在打 |
| 兵牌下方细条 | 只剩不到 95% 兵力时才出现：一眼看出打残了 |
| 虚线 + `3日` | 行军线：这支部队还要几天到 |
| 铁轨（浅灰带 + 刻度） | 铁路干线。铜色＝被炸坏，暗红＝炸断 |
| 双圈 | 车站（铁路转运点） |
| 方牌 `机` / `港` | 机场 / 港口 |
| 红色虚线大圈 | 舰队正在封锁这片水域 |
| 八条射线的爆点 | 今天这里有部队被空袭 |

## 4 省、阵地、展开宽度

**省**是地图的最小格子，**阵地**是省内的站位。一个省可以有 1–5 个阵地
（模块决定；不写就自动生成一个）。

| 概念 | 怎么理解 |
|---|---|
| 阵地名 | 比如「桥头堡」「张古山」—— 战报和公文里都按这个名字说话 |
| **展开宽度** 20%–100% | 这个阵地能同时投入多少兵。窄阵地塞不下太多人 |
| 容量 | `宽度 × 40 千`。超出容量的兵力只能当**预备队** |
| 工事 | 0–5 级，每级 +15% 防御；省级工事再叠 +8%/级 |

**怎么看阵地**：点一个省（或右键）→ 省会被切块，每块标着
`1 桥头堡 40% 砦3 ×2`＝第 1 个阵地、展开 40%、工事 3 级、当前驻 2 支部队。
我方兵牌会落在**自己那块**里。

**换阵地不花时间**：亲自指挥模式下指令栏有「阵地」一行，点一下部队就调过去
（`Shift`，不消耗天数）。这就是"留预备队"的用法 —— 也是窄阵地被塞满时唯一的解法。

## 5 部队与它的数字

| 数字 | 含义 |
|---|---|
| 兵力（千） | 这支部队还有多少人。**满编**是它的上限 |
| 士气 | 0–1。低士气打不动、也更容易溃 |
| 补给 | 0–1。低于 **0.15** 开始死人：每天减 0.5% 兵力、士气 −2% |
| 投入率 | 亲自指挥下的一个选项：按将领／六成／八成／全压。影响当场投入的兵力 |
| 被围 | 这一省和本方补给源断了联系，且四周都是敌人。被围的部队只有两条路：突围或待援 |
| 将领 | 名字、职务、性格四维（效忠/主动/好战/谨慎）、人物志 |
| 番号 | 军的编号。「并编」会让番号撤销，损失的不是人而是编制 |

## 6 两种指挥模式

在**设置**里切换（`亲自指挥` / `委诸将领`）。这是结构选择，不是难度档。

### 委诸将领（默认）

- 地图**只能看**，不能直接调兵；
- 唯一的命令入口是**电报台**：写人话发给某个部队或整个兵团；
- 将领按自己的性格理解你的话，可能照办、打折扣、抗命；
- 抗命会变成**请示公文**，你可以「准许」或「不准」 —— 不准就把原令钉住。

### 亲自指挥

- 点自己的兵牌 → 指令栏出现：**投入率** + **命令**（固守/整补/推进/并编，空军另有侦察/出击，海军有封锁）；
- 命令直接生效，**没有抗命**，将领只能在报告里表态；
- 「推进」需要再点一个目标省（可以点远处，部队会走过去）；
- 地图上多了「阵地」一行：可以即时调兵。

> 两种都能玩。想要"我说了算"就亲自指挥；想要"我说了、他怎么做"就委诸将领。

## 7 命令速查

### 地面部队

| 命令 | 干什么 | 耗时 |
|---|---|---|
| **固守** | 原地不动；亲自指挥下等于"顺手挖工事" | — |
| **整补** | 原地恢复补给与士气 | — |
| **筑工事** | 每 **3 天**把当前阵地工事 +1（最高 5）。**脚下有敌军就挖不动** | 持续 |
| **推进** | 打相邻的敌省；如果目标是我方省/敌空省，自动变成"进入" | 按行程 |
| **调兵** | 换到本省另一个阵地 | **不耗时** |
| **并编** | 把残部并入同省友军，本番号撤销 | — |
| **炸路**（空军） | 把目标省铁路炸坏一级 | 1 天 |
| **抢修** | 就地修一级铁路，**2 天**一级 | 2 天 |

### 空军

| 命令 | 干什么 |
|---|---|
| **侦察** | 只出情报（侦察半径内），**不投弹、不损耗** |
| **出击** | 打指定省；不指定则由引擎挑最值得炸的一个（优先自己地面部队在打的仗） |

空军每次出击损耗 0.3% 兵力（机组与飞机）。

### 海军

| 命令 | 干什么 |
|---|---|
| **推进** | 在水道间移动 |
| **封锁** | 切断**敌方沿岸省的海运补给**。陆路不受影响 |

## 8 将领与抗命

将领有四个数字：**效忠 / 主动 / 好战 / 谨慎**（0–1）。

- **抗命的概率**大致是 `(1 − 效忠) × 主动` 再乘一个军令权重 ——
  效忠高的基本不抗命；主动高、效忠低的会自己找事做。
- **抗命不是既成事实**：会先变成一封**请示**。你「不准」，这支部队就被钉在原令上
  （第二天也不会自己散掉）；你「准许」，它按自己的想法来。
- **"自己主张"和"抗命"不一样**：他判断该打而你想守，他可能主动出击；
  那是"将在外"，不是顶你。
- **撤换主官**（部分模块）：右键部队 → 撤换。代价是那一派在朝中的分量掉一截，
  这一局他不会回来。
- 将领的话**只是他的说法**，不是上帝视角：他会夸大、会报喜、会算错。

## 9 通信与延迟

| 概念 | 说明 |
|---|---|
| 命令延迟 | 电报发出后不是立刻生效，要过 `order_delay` 天（有线电报通常是 0，骑兵传令是 1） |
| 战报在途 | 顶栏显示「战报 N 份在途」：那是还在路上的消息，不是没发生 |
| 报告延迟 | 战斗、占领、空袭的报告都按通信条件延迟送达 |

**所以"昨天下的令今天没动静"是正常的** —— 先看战报里的「在途」，或看部队列表里
那支部队的当前命令。

## 10 情报与迷雾

- 敌情有**三档精度**：精确（打出来的）、近似（邻居观察，误差约 ±40%）、未知。
- **番号要接触两次才认得出**：第一次只知道"对面有多少人"，第二次才可能是"第 106 师团"。
- **情报会过期**：超过 3 天标"已过期"，数字可能早就不对了。
- **情报来源**影响延迟：战斗接触最快，航空侦察其次，邻接观察最慢。
- **敌方部队可以点**：会弹出「敌情」卡，显示我们**确实知道**的东西
  （番号或"未认出"、兵种、指挥官、所在阵地、当面兵力估计、情报来源、工事、是否被围）。
  注意：敌方没有"逐部队实数"，只有**省一级**的估计。

## 11 后勤：补给怎么流、怎么断

补给从**补给源**出发，沿地面逐省流动，每跳按通路衰减：

| 通路 | 每跳衰减 |
|---|---|
| 铁路（未炸断） | ×0.95 |
| 水道 | ×0.85 |
| 普通陆路 | ×0.75 |

三种"节点"会把补给**重新推上去**：

| 节点 | 效果 | 条件 |
|---|---|---|
| **车站** | 补给到这一省至少恢复到 **0.9** | 上一段也是铁路 + 这段没炸断 + 没有敌军踩在线上 |
| **港口** | 水路那一跳的损耗 0.85 → **0.95** | 这一跳的任一端有本方港口 |
| **补给源** | 直接 1.0 | 那一省是你的、且是补给源 |

两种"断法"：

| 断法 | 效果 |
|---|---|
| 敌军**地面部队**踩在你的补给线上 | 那一跳的通行能力 **×0.3**。截两段就基本断了 |
| 敌方舰队**封锁** | 从水上来的补给被切断（陆路不受影响） |

补给 < **0.15** 开始死人（每天 0.5% 兵力、士气 −2%），每 3 天报一次"断粮"。

**怎么看**：切到「补给」视图看颜色深浅；或看部队列表里的补给数字。

## 12 战斗怎么算

一句话：**双方火力各自算，再按"能展开多少"封顶，然后按损失比扣血。**

| 要素 | 影响 |
|---|---|
| 战斗力 | 兵力 × 装备/训练系数 × 士气 × 补给 × 弹药（若开着） |
| **展开宽度** | 每阵地 `宽度 × 40 千`。超出的部分默认**硬截断**；开了「连续正面」模型则按 **30%** 计入 |
| 地形 | 山地/城市防御加成高，平原低 |
| 工事 | 每级 +15%（省级 +8%） |
| 舰炮支援 | 沿海省若有本方舰队，火力加成 |
| 空袭 | 空军单独按天打击，不走上面的正面结算 |
| 抗命/打折扣 | 有异议但照令执行的部队，战力按 **0.85** 折 |

**围歼**：被围的部队撤退无路、补给归零，通常几天内被吃掉。想救就得**打破包围圈**
（打开一条通向我方补给源的相邻省）。

## 13 铁路被炸与抢修

- 铁路损坏 0–3 级：**0 通、1–2 坏、3 断**。
- 炸一级要 1 天（空军）；抢修 **2 天**一级（就地部队/工兵）。
- 炸到 3 级 = 这段退回普通陆路（×0.75），而且**这条线上的车站转运全部失效**。
- 所以"守住铁路"不是口号：前线部队的补给会立刻塌下来。

## 14 编制与人事

- 部队打到 0 就**覆灭**：番号从序列里划掉，将领随机得到一个结局
  （殉国 / 被俘 / 去职 / 突围生还），这个结局只有你们自己知道。
- **二次整编**：模块声明过、且将领还活着，才会在若干天后重建。没人就不会自动重建。
- **兵团部覆灭**：下属各部的服从度会掉一截（暂时没人压得住）。
- **并编**：把残部并进同省友军，番号撤销 —— 人还在，编制没了。

---

## 15 胜负与结局

- 战役有**固定天数**（模块决定）。到期就结束。
- 模块也可以声明**自己的结局条件**（守住某省、撑到某日、兵力低于某值……），
  满足即结束。结局文案由模块写，引擎只提供句式。
- 结算面板会给出「局面」而不是简单的"胜/败"——一场战役的结束是一个局面。

## 16 常见问题

**Q：我下了令，为什么部队没动？**
A：三种可能 —— ① 命令还在路上（看「在途」）；② 将领抗命了（看公文堆里的请示）；
③ 目标不可达（地形/战线不连续，看悬停提示）。

**Q：为什么打不动？**
A：先看三件事：① 你在这条阵地上的**展开宽度**是不是塞不下（容量 = 宽度×40 千）；
② 对方工事几级（`砦N`）；③ 你的补给和士气。

**Q：为什么我的补给突然塌了？**
A：查「补给」视图。常见原因：铁路被炸断、敌军踩在你的补给线上、港口被封锁、
补给源那个省丢了。

**Q：地图上的敌军数字为什么有时不显示？**
A：没侦察到就没有。邻接观察能给你近似值，航空侦察更快更准，但也可能过期。

**Q：为什么将领不听话？**
A：看他的效忠/主动。效忠低 + 主动高的将领最容易"自己拿主意"。
你可以「不准」把令钉住，也可以撤换 —— 但撤换有政治代价。

**Q：怎么让空军只侦察不出击？**
A：亲自指挥 → 选中空军 → 命令栏点「侦察」。侦察不损耗飞机。

**Q：封锁怎么用？**
A：亲自指挥 → 选中舰队 → 点「封锁」。它所在水域的**敌方沿岸省**海运补给被切断。
舰队必须先开到那片水域。

## 17 名词表

| 名词 | 含义 |
|---|---|
| 模块（.imod） | 一场战役的全部内容：地图、地形、编制、将领、规则、结局 |

| 番号 | 部队的编制编号。番号撤销 ≠ 人死光 |
| 投入率 | 亲自指挥下"这次压上去几成兵" |
| 抗命 | 将领拒绝或改动命令。会变成请示，不是既成事实 |
